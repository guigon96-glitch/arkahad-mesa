## 5. Perícias

Há **28 perícias**, graduadas de **0 a 5**. Na criação o personagem distribui **10 pontos** (mais bônus de raça, origem e estrato), com máximo **3** em qualquer perícia. Ganha **+2 pontos por nível**. Perícias marcadas com † não podem ser usadas com graduação 0.

| Perícia | Atributo base | Cobre |
| --- | --- | --- |
| Combate Leve | AGI | Adagas, espadas curtas, sabres, leques de guerra |
| Combate Pesado | FOR | Machados, espadas longas, martelos, alabardas |
| Pontaria | AGI | Arcos, bestas, fundas, arremesso |
| Briga | FOR | Desarmado, agarrar, derrubar, empurrar |
| Canalização | VON | Ataques e testes de Dom, sustentar técnicas, resistir a sintomas |
| Atletismo | FOR | Escalar, nadar, saltar, correr |
| Acrobacia | AGI | Equilíbrio, quedas, piruetas, escapar de amarras |
| Furtividade | AGI | Esconder-se, mover-se em silêncio |
| Ladinagem † | AGI | Fechaduras, armadilhas, punga, prestidigitação |
| Atenção | PER | Notar detalhes, emboscadas, sons |
| Rastreamento | PER | Seguir pegadas, ler sinais de passagem |
| Intuição | PER | Perceber mentiras, intenções, tensão social |
| Sobrevivência | PER | Orientação, abrigo, caça, clima |
| Natureza | INT | Fauna, flora, ervas, luas e estações |
| Medicina † | INT | Primeiros socorros, cirurgia, doenças, recuperação |
| Alquimia † | INT | Poções, venenos, óleos, antídotos |
| Conhecimento | INT | História, Códice dos Dons, facções, religião |
| Runas † | INT | Ler e ativar runas, relíquias pré-Queda |
| Tática | INT | Planejamento de combate, cerco, comando de tropas |
| Ofício | INT | Forja, carpintaria, joalheria, cristais (escolha um ramo por ponto) |
| Navegação | PER | Navios, dirigíveis, correntes, estrelas |
| Persuasão | PRE | Convencer, negociar com honestidade |
| Enganação | PRE | Mentir, disfarçar, blefar |
| Intimidação | PRE | Ameaçar, interrogar, quebrar moral |
| Etiqueta | PRE | Protocolo de corte, Conselho, cerimônias |
| Intriga | INT | Redes de espiões, boatos, chantagem, política |
| Comércio | PRE | Comprar, vender, avaliar, contratos |
| Montaria e Condução | AGI | Cavalgar, conduzir carroças e bestas de carga |

A perícia pode ser usada com outro atributo quando a ficção pedir (Atletismo + RES para nadar por horas; Intimidação + FOR para levantar alguém pelo pescoço). O Mestre decide.

### 5.1 Especializações

Com graduação 3 numa perícia, o personagem pode comprar uma **Especialização** (1 ponto de perícia): um foco estreito que dá **+2** (ex.: Combate Leve — Leques; Alquimia — Venenos de Tirith; Intriga — Corte de Kaerith; Ofício — Ferro Lunar).
