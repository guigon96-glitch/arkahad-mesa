## Apêndice A — Ficha de Personagem

Campos que toda ficha (de papel ou digital) precisa ter:

| Bloco | Campos |
| --- | --- |
| Identidade | Nome, título do Dom, Casa/sobrenome, raça e sub-raça, origem, estrato, Vocação, nível, XP |
| Narrativa | Conceito, Fardo, Juramento, Contatos, Cicatrizes |
| Atributos | FOR, AGI, RES, INT, PER, VON, PRE |
| Perícias | 28 perícias com graduação e Especializações |
| Recursos | Vigor (atual/máx.), Fôlego (atual/máx.), Tensão (atual/Limiar de Colapso), Brasas (0–3), Influência (0–5) |
| Defesas | Defesa, Robustez, Determinação, Limiar de Ferimento, Proteção, Proteção-Dom, Iniciativa, Deslocamento |
| Dom | Dom(s), nível, atributo-chave, técnicas conhecidas, variante, cristal (tipo, ressonância, estado: inteiro/rachado) |
| Combate | Armas (ataque, dano, propriedades), armadura, escudo, manobras favoritas |
| Estado | Condições ativas, Ferimentos, Sintomas |
| Inventário | Itens, Volume (atual/Carga), dinheiro (K/L/T), doses alquímicas |
| Mundo | Reputação por facção |
