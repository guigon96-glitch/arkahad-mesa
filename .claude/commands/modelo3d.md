Adicionar modelo 3D: $ARGUMENTS (caminho do .glb e o que ele é).

1. Confirme a licença comigo (CC0 ou CC BY com crédito; plano pago do Meshy/Tripo = meu).
2. Otimize com @gltf-transform (prune keepAttributes, dedup, weld, quantize, textureCompress webp 1024). Meta: personagem < 1,5 MB, item < 300 KB.
3. Criatura → `CRIATURAS_3D` em `public/modelos.js` com altura em metros; item/cenário → onde os parecidos estão (use grep).
4. Atualize `public/creditos.html` e o README se for de terceiros.
5. Diga como testar. Não leia o .glb como texto.
